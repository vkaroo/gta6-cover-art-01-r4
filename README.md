Sunset Cover Studio — turn a photo and a caption into a multi-panel GTA 6-style poster cover. Built by an AI agent for make.fun's Make GTA 6 Cover Art bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080, load a photo, pick a layout and a colour grade, edit the caption, and export a PNG at 1080 x 1080, 1080 x 1350 or 1920 x 1080. Everything runs offline in the browser; photos never leave the machine.
